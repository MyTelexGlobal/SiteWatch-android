# Сторонние компоненты

Автор исходного приложения: Александр Валерьевич Е, evstun@ya.ru.
Ревью кода и вычистка багов: Yury Myshinskiy.

Для сборки применяется измененный комплект Gradle 9.8.2, подготовленный для этого проекта 03.11.2026. Это не официальный выпуск Gradle. Официальный загрузчик Gradle Wrapper не изменен.

В комплекте заменена Guava 33.4.6-jre на официальный файл Guava 33.7.2-jre. Соответствующим образом изменены два описания пути загрузки классов. Файлы с изменениями помечены уведомлениями, происхождение записано в SITEWATCH-SECURITY-PATCH.json. Остальные файлы исходного дистрибутива сохраняются без изменения содержимого. Проверки находятся в tools/prepare_gradle.py.

Исходные LICENSE и NOTICE Gradle сохранены внутри архива. Исправленная Guava распространяется с исходными уведомлениями в ее JAR. Gradle и Guava применяют Apache License 2.0: https://www.apache.org/licenses/LICENSE-2.0

В приложении используются AndroidX WorkManager и его зависимости. Права на сторонние компоненты остаются у их правообладателей. Публикация этого проекта не меняет лицензии сторонних компонентов.
