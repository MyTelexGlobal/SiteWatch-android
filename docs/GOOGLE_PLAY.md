# Подготовка публикации в Google Play

Дата проверки требований: 03.11.2026.

## Статус

Приложение еще не опубликовано в Google Play. Пользователь создал личный аккаунт Play Console с публичным именем YuryMyshinskiy. В Console кнопка «Создать приложение» отключена до подтверждения аккаунта. Подтверждение личности, доступа к физическому Android-устройству и телефона еще требуется. Регистрация пакета, загрузка в Console, закрытое тестирование и рассмотрение Google не выполнены.

## Исправления приложения

Для следующей версии 1.6 установлен targetSdk 36 вместо 34. Для нового приложения обычных телефонов Google Play с 31.08.2026 требует API 36. При переходе добавлены отступы для системных панелей, вырезов и клавиатуры. Настройки прокручиваются, политика конфиденциальности читается без сети. При добавлении сайта объясняется передача запроса выбранному серверу, включая работу в фоне.

Подготовлены тексты карточки магазина, материалы для проверяющего и перечень обработки данных в publishing/google-play. APK и подписанный AAB собраны и проверены. Прошли 16 автоматических тестов и 11 групп проверки эмулятора. APK из AAB установлен на отдельном образе Google Play. Штатное сканирование Play Protect выпуска APK завершилось сообщением «No harmful apps found», СайтКонтроль указан среди проверенных приложений. Это не одобрение магазина. [Подтвержденные результаты и ограничения](TESTING.md).

## Действия для прозрачности и проверки

1. Открытые исходники, отчеты и контрольные суммы позволяют сверить происхождение установочного файла.
2. Сохранение ключа подписи позволяет проверить последующие обновления. Сертификат Android подтверждает подпись, но не личность издателя у Google.
3. Публичная политика и ее текст в приложении описывают хранение, получателей запросов, HTTP и удаление данных.
4. Имя приложения в User-Agent заменяет строку, выдававшую запрос за браузер Chrome.
5. Следующие шаги в Play Console: подтвержденная личность издателя, регистрация ru.sitewatch.monitor, Play App Signing, проверка AAB, предварительный отчет Google, реальное тестирование и рассмотрение выпуска.

Ни один из этих шагов сам по себе не гарантирует снятие предупреждения Play Protect. Без точного сообщения и результата проверки Google причина предупреждения на пользовательском телефоне остается неизвестной. Жалоба на ошибочное обнаружение вредоносного ПО не подается только ради предупреждения о незнакомом APK.

## Требования, которые нельзя заменить локальными проверками

Новый личный аккаунт требует единовременного взноса 25 долларов США, данных настоящего владельца и подтверждения личности. Google также требует подтверждения доступа к Android-устройству. Для допуска к открытой публикации нужен закрытый тест минимум с 12 участниками, непрерывно подключенными не менее 14 дней, и последующее одобрение заявки на доступ. Тестовые учетные записи и вымышленные ответы не используются.

Условия Google, платежный профиль и личные документы должен проверить владелец. Данные открытого профиля издателя не обязаны совпадать с авторством кода. Автор приложения в проекте остается Александр Валерьевич Е, evstun@ya.ru; ревью кода и вычистка багов: Yury Myshinskiy.

## Подпись и обновления

У APK из GitHub и APK, которые Google сформирует из AAB, должен быть один ключ подписи приложения для обычного обновления поверх установленного экземпляра. Для существующей версии это сертификат d0ec938d2f94601baf545510183ff5769b68c57929cfd16023aa8b0277908537.

Не следует молча выбирать новый ключ подписи приложения, автоматически создаваемый Google, если нужен переход с установленного GitHub APK без удаления данных. В Console нужно выбрать импорт существующего ключа через предложенный Google механизм. Отдельный ключ загрузки нужен для передачи AAB; он не определяет подпись устанавливаемого Google APK. Закрытые ключи нельзя выкладывать в GitHub или передавать в обычных сообщениях.

## Анкеты и материалы

В приложении нет аккаунтов, рекламы, покупок и собственного сервера телеметрии. Однако оно отправляет запросы к выбранным пользователем серверам. Для анкеты «Безопасность данных» подготовлен перечень фактических данных. Нельзя автоматически ответить «данные не собираются» только из-за отсутствия сервера разработчика: определение Google учитывает передачу за пределы устройства. Исключение для ожидаемой пользователем передачи третьей стороне относится к вопросу о передаче другим лицам и рассматривается отдельно.

HTTP остается доступен по отдельному согласию. Поэтому ответ «все передаваемые данные зашифрованы» был бы неверным. Хранение журналов на произвольных сайтах не контролируется приложением; обещание их немедленного удаления или временной обработки было бы необоснованным. Окончательные ответы анкеты должны соответствовать фактическим полям Console и опубликованной политике.

Окончательный возрастной рейтинг определяется анкетой IARC. Страны распространения и публичные данные издателя пока не выбраны. Название, описания и примечания для проверяющего подготовлены; никаких одобрений, рейтингов или значков доверия в них не заявлено.
